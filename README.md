# GBM — موقع خدمة إدارة ملفات Google Business Profile + نظام تقييمات QR/NFC

موقع ثابت (HTML/CSS/JS) بالعربية RTL لخدمة B2B تساعد المحلات والأنشطة المحلية تظهر على خرائط جوجل وتجمع تقييمات حقيقية.

## الملفات
- `index.html` — الصفحة الرئيسية (صفحة واحدة بكل الأقسام)
- `styles.css` — التنسيقات (داكن فخم + ذهبي، خط Cairo)
- `script.js` — قائمة الموبايل + زر التواصل (placeholder)

## الحالة
نسخة أولية (draft) — غير منشورة. رابط التواصل لسه placeholder لحد ما يتحدد رقم الواتساب/نموذج التواصل.

## التشغيل محليًا
افتح `index.html` مباشرة في المتصفح، أو:
```bash
python3 -m http.server 8000
```

## النشر لاحقًا (بعد موافقة صاحب المشروع)
ممكن يتنشر مجانًا على GitHub Pages من إعدادات الريبو (Settings → Pages → main branch).

## المرجع
مبني على الخطة الموحدة للمشروع (محفوظة على Google Drive في فولدر "QR + GBP Business").
